# Anime Player

Кастомный видеоплеер для аниме/сериалов/фильмов с собственным бэкендом и админ-панелью — от вёрстки одного HTML-плеера до полноценного маленького стриминг-сервиса.

Стек: **React + TypeScript** на фронте, **Express + TypeScript + Drizzle ORM + PostgreSQL** на бэке.

---

## Возможности

### Плеер
- Кастомные контролы: play/pause, перемотка, буферизация, громкость, PiP, полноэкранный режим.
- Прогресс-бар с превью кадра и временем при наведении/перетаскивании — как в YouTube.
- Клавиатурные шорткаты: `Space`/`K` — пауза, `←`/`→` — перемотка на 5с, `J`/`L` — на 10с, `↑`/`↓` — громкость, `M` — mute, `C` — субтитры, `F` — полный экран, `0–9` — переход на N×10% видео.
- Автопродолжение просмотра — плеер помнит серию и момент, где остановился зритель.
- Настраиваемые качество видео, язык субтитров, скорость воспроизведения.
- Автопропуск опенинга/эндинга (таймкоды задаются в админке), автовоспроизведение следующей серии.
- Панель сезонов и серий, переключение серии кнопками рядом с play.
- Поиск по каталогу прямо из плеера.
- Информация о тайтле и «Поделиться» (обычная ссылка / embed-код / QR-код) — с возможностью указать таймкод.
- На мобильных: двойной тап по краю экрана — перемотка, полноэкранный режим разворачивает экран в альбомную ориентацию.

### Админ-панель
- Каталог тайтлов с поиском и карточным редактором.
- Постеры отдельно для мобильной и десктопной версии, жанры, автор, год, описание.
- Связанные тайтлы (сиквелы, спин-оффы и т.п.) с сортировкой перетаскиванием.
- Сезоны с привязкой студии озвучки, перетаскиваемым порядком, инлайн-переименованием.
- Серии: несколько источников видео на разное качество, субтитры, таймкоды опенинга/эндинга, обложка серии.
- Общий логин на весь сайт (каталог + плеер + админка), быстрое переключение "Каталог / Админка".

## Быстрый старт

### 1. База данных
Нужен локальный или удалённый PostgreSQL. Создай базу данных, например `anime_player`.

### 2. Backend
```bash
cd server
cp .env.example .env      # укажи DATABASE_URL, JWT_SECRET, ADMIN_EMAIL/ADMIN_PASSWORD
npm install
npm run db:push           # накатить схему
npm run seed:admin        # создать первого администратора
npm run dev                # http://localhost:4000
```

### 3. Frontend
```bash
cd client
npm install
npm run dev                # http://localhost:5173
```

Дальше залогинься на `http://localhost:5173` учёткой из `.env` — откроется каталог, из него можно перейти в админку и наполнить сайт контентом.

## Известные ограничения

- Загрузка видео/постеров — по прямой ссылке (URL). Реальной загрузки файлов на сервер (S3 и т.п.) пока нет — при желании подключается отдельно.
- Один администратор из `.env`, без ролей и множественных аккаунтов.
- Защита видео от скачивания — на уровне отключённого контекстного меню; полноценная защита (DRM) потребует HLS + Widevine/FairPlay, это отдельная инфраструктура.
- QR-код в "Поделиться" генерируется через внешний сервис (api.qrserver.com) — для полностью автономной работы стоит заменить на локальную генерацию.
